### 一句话总结

FIND 通过 B-Spline 图频域滤波与双流一致性学习，在测试时分离 LiDAR 点云中的稳定几何内容和域相关干扰，相比已有最佳方法在两个跨数据集检测任务上平均提升 +2.27 AP_BEV、+3.24 AP_3D，但其属于需要在线更新的 Test-Time Adaptation（TTA），并非仅依赖源域训练的 single-domain generalization。

### 问题与动机

LiDAR 3D Object Detection 在传感器线束配置、采样模式、地点和天气变化下会明显退化。论文关注 Fully TTA：不改变源模型训练目标，在部署阶段利用无标注目标数据在线更新检测器，适应过程中不访问源域样本。

作者认为，现有方法主要通过空间扰动、一致性学习或模型集成适应域偏移，容易将点云的目标几何结构与传感器噪声、采样风格混淆。直接把高频当作噪声也不可靠：低频包含整体形状，中频影响结构完整性，高频同样承载车轮等细节。

论文的频谱分析给出三个设计依据：

- 域差异分布于整个频谱，固定频带删除可能破坏语义几何。
- 相邻频段的跨域 spectral energy KL divergence 波动较大，需要局部可调滤波。
- 域内 spectral energy 的 Coefficient of Variation（CV）与跨域 KL divergence 呈正 Spearman correlation，因此可用无标注目标域统计近似指示哪些频段更稳定。

**关键判断：CV 是域不变性的经验代理，而不是语义与风格可被严格分离的证明。** 给出的正文没有列出相关系数的具体数值。

### 方法要点

- **基于预测框构造语义局部图。** 在预测 bounding boxes 内提取点云，中心化后构造 Gaussian-weighted kNN graph，对 normalized Graph Laplacian 做特征分解，得到 Graph Fourier Transform（GFT）表示。这样将频谱分析限制在候选目标区域，但也引入了对初始检测质量的依赖。

- **用 B-Spline 实现局部可学习频响。** 将特征值范围 `[0,2]` 划分为频段，通过可学习端点响应和固定 B-Spline 基函数生成滤波器。优化端点响应，再经可微线性映射得到系数；默认 `N=12`、`K=3`。其意图是独立调节局部频段，避免全局 polynomial filter 牵动整个频谱。

- **Invariant Stream 保留原始坐标，通过选点保护几何。** 先计算滤波点云，再根据滤波前后点坐标范数之比生成二值 mask；检测器实际接收的是被选中的**原始点坐标**，而非直接输入重建后的变形点云。这与保持目标几何的兴趣直接相关，但删除点仍可能损伤稀疏目标。阈值初值为 `0.2`，EMA 系数为 `0.001`。

- **Specific Stream 注入域相关扰动。** 提取频域 specific components，构造 `X + ε_r X_sp`，其中 `ε_r` 从 `(-1,1)` 采样。Invariant Stream 的输出作为 pseudo-labels，使用原检测器的源训练损失约束 Specific Stream，使预测对域相关扰动保持一致。

- **用稳定性与互补性共同约束解耦。** 部署前利用源域 spectral energy CV 初始化 Invariant filter；部署后仅累积目标域一、二阶矩，构造稳定性 mask。稳定性损失引导两类滤波器分别抑制不稳定和稳定频段，互补损失约束 `h_in + h_sp ≈ 1`，避免退化解；默认 `τ=10`，两项损失权重分别为 `0.8` 和 `0.6`。

### 实验

**设置与基线。** 主干统一为 SECOND-IoU，batch size 为 `8`，优化器设置沿用 MOS。任务包括 nuScenes/Waymo → KITTI、KITTI → KITTI-C，以及 Waymo → KITTI-C；附录增加 Waymo → nuScenes。基线包括 Tent、CoTTA、Reg-TTA3D、MOS、DUO，并补充 SC-NNK、L-TTA、SPA。以下主结果为 Car、moderate detection difficulty；corruption severity 与检测难度应区分。

**跨数据集主要结果：**

| 方法 | nuScenes → KITTI AP_BEV / AP_3D | Waymo → KITTI AP_BEV / AP_3D |
|---|---:|---:|
| Source | 45.50 / 13.78 | 65.64 / 26.74 |
| Oracle | 83.29 / 73.45 | 83.29 / 73.45 |
| Tent | 45.13 / 19.33 | 68.54 / 34.57 |
| CoTTA | 68.81 / 47.61 | 67.46 / 35.34 |
| Reg-TTA3D | 70.21 / 49.32 | 81.60 / 61.03 |
| MOS | 71.13 / 51.11 | 81.90 / 64.16 |
| DUO | 69.85 / 50.08 | 75.38 / 62.39 |
| **FIND** | **75.21 / 54.66** | **82.35 / 67.09** |

相对 MOS，FIND 在两个任务上的 AP_3D 分别提高 +3.55、+2.93。Waymo → KITTI 的 AP_BEV 接近 Oracle，但 AP_3D 仍有差距，不能将鸟瞰定位改善等同于完整 3D 框恢复。

**Corruption 与频域方法对比：**

| 方法 | KITTI → KITTI-C，heavy，平均 AP_3D | Waymo → KITTI-C，heavy，平均 AP_3D |
|---|---:|---:|
| Source | 54.95 | 14.41 |
| CoTTA | 55.68 | 26.39 |
| Reg-TTA3D | 56.88 | 31.86 |
| MOS | 57.48 | 32.62 |
| DUO | 56.96 | 31.14 |
| **FIND** | **59.62** | **33.99** |

- KITTI-C 包含 `8` 类 corruption。FIND 在 heavy severity 上相对 MOS 平均提升 +2.14 AP_3D；Incomplete echoes（Inc.）达到 `38.49`，相对 Source 提升 +11.00。
- FIND 并非每项 corruption 都最优：KITTI → KITTI-C 的 Rain 为 `78.23`，低于 DUO 的 `78.49`。
- KITTI → KITTI-C 在 moderate、easy severity 下，FIND 平均 AP_3D 分别为 `62.69`、`74.81`，MOS 为 `61.82`、`74.16`。
- SC-NNK、L-TTA、SPA 在 nuScenes → KITTI 的 AP_3D 分别为 `42.69`、`44.57`、`48.19`，低于 FIND 的 `54.66`，支持收益不只来自一般点云去噪。

**关键消融：**

| 配置 | nuScenes → KITTI AP_3D | Waymo → KITTI AP_3D |
|---|---:|---:|
| Source | 13.78 | 26.74 |
| 仅一致性损失 | 48.81 | 58.93 |
| 一致性 + 稳定性损失 | 52.49 | 64.48 |
| 完整 FIND | **54.66** | **67.09** |
| Rigid filters | 32.56 | 39.10 |
| Global polynomial filters | 48.38 | 50.21 |

一致性学习提供主要收益，稳定性与互补约束进一步改善结果；B-Spline 明显优于固定频带及全局 polynomial filter。不过，后者与 B-Spline 的初始化方式不同，尚不能完全排除初始化先验对差距的贡献。

**持续适应与失败条件。** 在不重置、无域标签的 Fog → Rain → Snow 流上，FIND 平均 AP_3D 从 Independent 的 `71.46` 降至 Continual 的 `71.09`，下降 `0.37`；MOS 下降 `1.04`。预测框扰动实验中，删除 `10%` boxes 的影响最大：Waymo → KITTI-C 从 `33.99` 降至 `32.39`，低于 MOS 的 `32.62`。这给出了较明确的适用边界：缺失有效目标区域会削弱其优势。

**算力与效率。** 单张 NVIDIA RTX 4090、batch size `8`：

| 方法 | 每点云 Time（ms） | 最大 CUDA Memory（MiB） |
|---|---:|---:|
| CoTTA | 179 ± 10 | 10,462 |
| MOS | 3088 ± 160 | 14,134 |
| DUO | 158 ± 8 | 8,312 |
| FIND | 194 ± 18 | 11,540 |

FIND 的 spectral filtering 为 `27 ms`、占 `13.92%`；dual-stream adaptation 为 `88 ms`、占 `45.36%`。单卡复现的显存需求较合理，但在线更新开销明显，不能据此认定满足实时部署要求。

### 局限与可追问点

- **解耦证据仍以相关性和性能为主。** CV 高可能来自传感器变化，也可能来自物体姿态、尺寸或类别分布。应验证控制这些语义因素后，CV 是否仍能识别域干扰；论文提到的固定几何分析对应 Appendix B，但给定内容未包含其具体结果。

- **硬选点的梯度路径不清楚。** Invariant Stream 通过二值 mask 选择原始点，普通自动微分无法穿过离散选择。论文声称联合优化滤波器，但该分支是否使用梯度近似、pseudo-label 是否 stop-gradient、两流参数如何共享或更新、最终由哪一路输出检测结果，文中未说明。

- **滤波范围与数值约束需要核实。** 初始化端点位于 `[0,1]`，但优化期间如何限制端点及 B-Spline 插值后的整体响应，文中未说明。若响应可以为负，线性形式的稳定性损失可能出现不符合预期的优化方向；还需核查接近零的能量均值、点坐标范数和空选点集合如何处理。

- **部分消融的更新机制存在疑问。** 表中“仅稳定性损失”以及“稳定性 + 互补损失”没有检测一致性监督，却带来明显收益。需要说明这些变体更新哪些参数、使用哪一路推理，以及收益来自输入过滤还是检测器适应。
