### 一句话总结

论文提出免训练、免梯度的 AgentNorm，通过为受损协作者单独估计当前帧 BN 统计量、为干净 ego 保留源域统计量，缓解相机协同检测中的异质域偏移，在 OPV2V 的 fog 和 motion blur 下较 Pooled BN 提升 5.53–12.94 个 AP@0.5 点，但无法可靠处理遮挡造成的信息丢失。

### 问题与动机

论文研究的是**相机中间特征融合协同感知中的 agent-specific corruption**：ego 相机保持干净，部分协作者相机受到 fog、motion blur 或曝光变化影响，其共享 BEV 特征发生分布偏移，进而损害融合检测。

这一问题不仅表现为“协作者没有贡献”，还可能使协作比单车检测更差。例如，OPV2V 上 AttFuse 在协作者受到 severity-5 fog 时仅有 37.25 AP@0.5，低于 Ego only 的 38.31。

现有补救方案存在以下不足：

- **训练时增强或 domain generalization**需要重新训练部署模型，并选择预期的腐蚀类型。
- **丢弃协作者或屏蔽异常区域**会同时删除可能有用的信息；统计变化大的区域也未必对检测有害。
- **梯度式 TTA**可能受密集检测中的前景／背景不平衡影响。论文测试的 Tent-style entropy minimization 出现严重退化，但这不能代表所有梯度式 TTA。
- **Pooled BN**将同一帧所有 agents 混在一起估计统计量，混合统计既不能充分校正受损协作者，还会改变干净 ego 的特征。论文通过移除融合输入、仅用 ego 特征检测的实验，测得这种污染使 ego 自身下降 3.58–6.68 个 AP@0.5 点。

核心动机是：**域偏移具有 agent 归属，归一化统计量也应按 agent 区分。**

### 方法要点

- **Agent-wise statistics：按协作者估计当前帧统计量。** 在每个可按 agent 切分的 BN 层，对协作者自己的输入计算逐通道均值和方差，替换源域 running statistics，保留原有 affine parameters。图像 backbone 在该 agent 的相机视图和空间位置上聚合，BEV backbone 在自身 BEV 空间位置上聚合。

- **Ego anchoring：保护干净 ego 的编码路径。** ego 始终使用训练时保存的源域 BN 统计量，使其自身特征保持为源模型输出。这个保证针对的是 **ego 编码特征**；受损协作者仍可能通过后续融合损害最终检测，因而不构成融合性能下界保证。

- **用统计混合公式解释 Pooled BN 的失配。** 混合方差包含 agent 内方差与 agent 间均值差异项，因此会引入额外尺度变化；使用混合统计归一化后，各 agent 仍有残余均值偏移与尺度误差。所有 agents 具有相同统计分布时，这一优势预期消失。

- **逐帧、无状态地校正。** 不更新模型参数、不使用标签或源数据，也不跨帧积累统计量，因此结果与测试帧顺序无关。各协作者可在本地完成归一化，传输特征的格式和大小不变。

- **适用范围取决于 BN 与 agent 切分。** 无法按 agent 切分的层保留源统计量；仅使用 LayerNorm 或 GroupNorm 的编码器不能直接套用。论文的 OPV2V 实现将同一帧所有协作者合为一组归一化，因此它对“不同协作者同时遭遇不同偏移”的验证仍不充分。

### 实验

**数据集与设置。** OPV2V 使用完整测试集 2,170 帧，其中 2,051 帧包含协作者，每车四个相机；评估 HEAL 的 AttFuse、V2X-ViT、DiscoNet 和 AttFuse-B。AttFuse-B 虽以 F-Cooper 名义发布，但配置实际采用 attention fusion，不能视作 max-pooling fusion 的实验依据。四个 checkpoint 共用 Lift-Splat-Shoot 与 EfficientNet-B0 编码架构。

真实数据实验使用 DAIR-V2X-C 的 1,789 个验证帧，作者自行训练 camera-only CoAlign，训练 30 epochs，并按 validation loss 选择 checkpoint。主要报告 AP@0.5 和 AP@0.7。默认仅腐蚀协作者，severity 为 3 和 5。

**对比方法。** 包括 No adaptation、Ego only、Pooled BN、region gating、Feature-statistics alignment、Tent-style entropy minimization，以及使用真实标签优化协作者 BN affine parameters 的 Oracle；Oracle 仅作参考，不是合法的无监督测试时方法。

**OPV2V 主要结果：severity 5，仅协作者受损。** 下表数字均为百分比；增益照抄原文，个别项与表内两位小数直接相减存在末位差异。

| Model | Corruption | No adaptation AP@0.5 | Pooled BN AP@0.5 | AgentNorm AP@0.5 | 原文增益 | AgentNorm AP@0.7 |
|---|---|---:|---:|---:|---:|---:|
| AttFuse | Fog | 37.25 | 40.65 | 51.98 | +11.34 | 24.35 |
| AttFuse | Motion blur | 36.48 | 42.90 | 49.83 | +6.93 | 22.88 |
| V2X-ViT | Fog | 29.69 | 45.92 | 58.86 | +12.94 | 27.98 |
| V2X-ViT | Motion blur | 33.51 | 46.36 | 55.45 | +9.10 | 26.61 |
| DiscoNet | Fog | 33.33 | 43.73 | 51.57 | +7.85 | 23.63 |
| DiscoNet | Motion blur | 31.56 | 42.89 | 48.42 | +5.53 | 21.18 |
| AttFuse-B | Fog | 29.42 | 30.79 | 43.32 | +12.53 | 19.09 |
| AttFuse-B | Motion blur | 31.31 | 32.36 | 42.80 | +10.45 | 18.07 |

Fog 与 Motion blur 的八种组合中，AgentNorm 均优于 Pooled BN。AttFuse 的 Fog 设置中，Oracle 达到 57.13 AP@0.5，AgentNorm 弥合 No adaptation 与 Oracle 之间差距的 74%。

优势并不覆盖所有腐蚀：Brightness 下两种归一化方法各赢两个 checkpoint；Occlusion 下 AgentNorm 在四个 checkpoint 中有三个低于 No adaptation，例如 AttFuse 从 39.92 降至 35.63。

| Corruption | No adaptation AP@0.5 | Pooled BN AP@0.5 | AgentNorm AP@0.5 |
|---|---:|---:|---:|
| Fog | 1.50 | 2.07 | 5.88 |
| Snow | 1.16 | 2.44 | 5.17 |
| Frost | 1.30 | 2.71 | 5.40 |
| Brightness | 1.17 | 3.79 | 6.08 |

合计两个 severity 的十种受损设置，AgentNorm 全部超过 Pooled BN，其中九种超过 No adaptation。但 clean 输入只有 10.83 AP@0.5，作者也明确将其视为方向性验证，不能据此推断成熟部署系统中的收益规模。

**消融与机制分析。**

| AttFuse 设置 | Fog AP@0.5 | Motion blur AP@0.5 | 结论 |
|---|---:|---:|---|
| No adaptation | 37.25 | 36.48 | 源模型参考 |
| 仅 BEV backbone 使用 agent-wise statistics | 31.37 | 31.43 | 单独校正末端 BEV 反而退化 |
| 仅 image encoder 使用 agent-wise statistics | 51.92 | 49.39 | 已接近完整方法，主要收益来自图像编码阶段 |
| AgentNorm | 51.98 | 49.83 | 完整方法 |
| Agent-wise, symmetric | 53.11 | 50.69 | ego 也使用自身当前统计量，AP@0.5 更高 |
| AgentNorm, EMA statistics，m=0.05 | 51.12 | 文中未说明 | Fog 下低于逐帧统计，并引入顺序依赖 |

Ego anchoring 并非 AP@0.5 最优选项：symmetric variant 在表中五种条件下均更高，但 anchored variant 的 AP@0.7 均更高，体现定位质量与较宽松 IoU 表现之间的取舍。当 ego 和协作者受到相同腐蚀时，symmetric agent-wise statistics 与 Pooled BN 的 AP@0.5 差距均在 1.01 点以内，支持“收益主要来自跨 agent 分布异质性”的解释。

**效率与失败案例。** 单张 RTX 3090 上，平均时延由 254.32 ms 增至 256.65 ms，增加 2.33 ms，峰值显存均为 2669 MB。可视化明确选取了候选帧中的最佳收益案例；同时报告全部 115 个候选帧，AgentNorm 比 No adaptation 检出更多目标的有 84 帧，更少的有 8 帧，避免仅靠最佳案例论证。

### 与你研究的关系

**与跨域检测鲁棒性高度相关，与 single-domain generalization 的关系主要在机制和互补性上。** 论文从干净源域模型出发处理未知腐蚀，但测试时使用当前输入重新估计统计量，属于 test-time normalization，不是固定模型直接部署的严格 single-domain generalization；也未通过风格迁移或图像转换生成训练样本。

最值得借鉴的是以下几点：

- **把域偏移的粒度纳入设计。** 一批数据可能包含不同域，不能默认共享一套目标域统计量。对于多相机、多传感器或多来源风格增强，这一观察比简单“整体对齐源域与目标域”更具体。
- **用低成本基线检验风格增强收益。** AgentNorm 无需重新训练，可用于判断你的风格增强检测器是否仍依赖外观的一、二阶统计，以及训练增强与测试归一化是否互补。
- **借鉴其定位机制的实验设计。** “仅用 ego 特征检测”将归一化污染与融合污染分离；image encoder／BEV backbone 分层消融，则定位了有效干预位置。这类受控实验适合分析风格变化究竟影响了检测器哪一阶段。
- **它不直接改写图像像素或几何，可作为语义保持方案的对照。** 但论文没有按目标尺度报告结果，也未验证小目标细节、边界框稳定性或语义一致性，不能将“不做图像转换”等同于“已证明保护细节”。
- **复现算力较友好，但资源开放性不足。** 主要方法只修改推理 BN，单张 RTX 3090 即可评估；没有实现链接会增加工程复现成本。

### 局限与可追问点

- **真正的多协作者异质性尚未充分验证。** OPV2V 将所有协作者合组估计统计量，理由是它们采用相同腐蚀；但相同腐蚀不保证不同场景、视角的特征均值和方差相同，合组统计也不严格等价于逐 agent 统计。应比较严格逐 agent、协作者分组与全体 pooled 三种实现，并让不同协作者同时遭遇不同腐蚀和 severity。

- **干净 ego 是默认前提，保护特征不等于保护最终检测。** 实际部署中 ego 也可能偏移；symmetric variant 虽有实验支持，但如何在未知条件下选择 anchoring 或 symmetric，文中未解决。Occlusion 下的退化也说明最终输出没有“至少不差于 Ego only”的保证。

- **统计修正无法恢复缺失内容。** 遮挡不仅改变统计量，还删除了观测证据。值得验证与缺失内容检测、可靠性融合权重的组合，但论文结果也提醒：简单屏蔽“统计异常最大”的区域不可靠。

- **真实跨域证据有限。** 主要测试是干净数据上施加合成腐蚀；DAIR-V2X-C 虽为真实数据，腐蚀仍是人工添加，且模型绝对性能较低。真实恶劣天气、跨城市和跨相机设备的检测效果文中未说明。

- **架构覆盖与小目标证据不足。** 四个主要 checkpoint 共享编码架构，不能替代跨 backbone 验证；对 LayerNorm／GroupNorm 编码器不直接适用。单视图、低分辨率、小目标和远距离目标上的统计估计稳定性值得单独评估。

- **部分结论应限定范围。** Tent-style baseline 修改了原始 Tent 的统计量处理方式，且梯度基线仅用一个 seed，不能据其崩溃否定其他 TTA。Clean OPV2V 上 Pooled BN 优于 AgentNorm，而 DAIR-V2X-C 上 AgentNorm 低于源模型，也说明无条件启用并非普遍无损。

- **评估与资源仍有复现疑点。** 作者自己的 clean AttFuse 为 56.81 AP@0.5，随 checkpoint 发布的评估文件为 52.91；论文通过统一内部评估避免混用，但差异原因文中未说明。后续应核对评估配置、严格逐 agent 实现、运行时封装及开源计划。
